# SETUP — где какие настройки

Проще всего менять словами: «музыку тише», «убери зерно». Claude сам поправит нужный
файл. Эта шпаргалка нужна, чтобы понимать, где что лежит и на что влияет.

Два уровня:
- **Бренд** (`brand/`) — действует на все рилсы.
- **Рилс** (`video-projects/<дата-слаг>/`) — только на один ролик.

`lessons.md`, `refs/NOTES.md` и `brand/music/tracks.json` — твои локальные файлы, в гит не
попадают. `brand/brand.md` лежит в гите (репозиторий приватный). `npm run setup` (или первый
`/reel`) создаёт недостающие из шаблонов `*.example`. Меняй свой файл, шаблон не трогай.

## Запуск рилса

```
/reel <файл> — бриф одной строкой [--mode kit|full] [--density light|medium|heavy] [--review-cuts] [--principles]
```

| Флаг | Что |
|---|---|
| `--mode kit` | по умолчанию: монтаж, графика, субтитры, превью |
| `--mode full` | сразу готовый MP4 |
| `--density` | сколько графики: light 2–4 в минуту, medium 4–7, heavy почти на каждой фразе |
| `--review-cuts` | показать список вырезанного до сборки |
| `--principles` | проверить речь по принципам удержания (см. ниже); выключено по умолчанию |

Паузы между фразами — 0,08 с, по громкости звука, а не по словам расшифровки (`scripts/ru/wide/env-cuts.py`,
`--keep`). Видео начинается сразу со слова. Ускоренная версия превью и финала — по плотности речи: 3,45 ÷ слов
в секунду, от ×1,05 до ×1,12 (плотный текст — ×1,05); скажешь своё число — будет оно.

Светлый стиль, OBS-дубль (камера-карточкой снизу): на ровной стене без мебели смены фона идут с маской — комната и рамка
карточки уходят, ты на тёмном фоне (`scripts/ru/wide/obs_swaps.py`); если у плеча кресло — без маски,
темнеет всё вокруг карточки.

## Повторить чужой рилс

```
/remake <файл чужого рилса> — бриф: тема, что оставить, что поменять [--slug name] [--principles]
```

Claude разбирает рилс (сюжет, хук по кадрам, ритм, графика, съёмка, звук по цифрам),
пишет текст под тебя и план съёмки по локациям и ждёт «да» (ГЕЙТ R). Всё лежит в
`video-projects/<дата>-remake-<слаг>/`: `BREAKDOWN.md` — разбор, `SCRIPT.md` — сценарий,
`SHOOT.md` — карточка для съёмки. Факты, которых Claude не знает про тебя, помечены
`[проверь]`. Кадры, звук и текст чужого рилса в твой ролик не попадают.

Снял — запусти обычный монтаж со сценарием:

```
/reel inbox/<файл> --remake video-projects/<дата>-remake-<слаг>
```

| Флаг | Что |
|---|---|
| `/reel … --remake <проект>` | сценарий ремейка — основа для чистки (дубли) и плана графики |

## Быстрый ремейк

```
/remake-fast <файл чужого рилса> — бриф [--principles]
```

Без согласований на середине: Claude сразу отдаёт `SAY.md` — что говорить (🎧 — фразы, где тебя
закрывает врезка: их можно читать с листа) и `SCREEN.md` — что записать с экрана и куда кликать.
Вопросы «проверь» Claude решает сам и перечисляет решения. Снял — клади всё в `inbox/<слаг>/` и
запусти `/remake-fast video-projects/<дата>-remake-<слаг>`: дальше превью (обычное и ускоренное),
«да» — финал, ускоренная версия (`renders/final.x<F>.mp4`, скорость как на одобренном превью) и текст для
Instagram (`CAPTION.md`).
Ремейки идут в ночном стиле (`fx/fx.json` → `"look": "night"`): ночной фон, ты вырезан маской, предметы-чертежи, 1–2 светлых акцента; к превью — таблица движений `MOTION.md`. Старый светлый вид — по просьбе («как раньше, светлый»).

| Скрипт | Что |
|---|---|
| `node scripts/ru/footage-check.mjs <проект ремейка>` | что отснято против `SCREEN.md`, где дубль, высоко ли голова (тогда `relocate`) |
| `node scripts/ru/speed-variant.mjs <проект> --factor 1.1` | ускоренная копия готового рилса (картинка, графика, субтитры и звук вместе) |
| `python3 scripts/ru/wide/gaps.py <проект> [t0-t1 …]` | звук без слов в расшифровке (щелчки, кашель, пропущенные дубли) и дорасшифровка выбранных фраз → `work/GAPS.md` |
| `python3 scripts/ru/wide/obs_swaps.py <проект> --prep`, затем без флага | Светлый стиль: смены фона с маской для OBS-дубля: маски, тёмный слой с текстом, ты поверх |
| `node scripts/ru/motion-check.mjs <проект>` | раскадровка движений: `PLAN.json` → `motion`, записи `{at, word, verb, what}` (время в секундах, слово из расшифровки, глагол, что в кадре; 16 id глаголов перечислены в начале `scripts/ru/motion-check.mjs`). Глагол не два раза подряд, не меньше пяти разных, 1–2 светлых акцента → `MOTION.md` |
| `python3 scripts/ru/wide/night_base.py <проект> --prep`, затем `--stills 1.0,4.6` и `--mix` (`--card` — без маски; `--allow-missing` — не останавливаться, если больше 5 % кадров без своей маски) | ночная база картинки: маски, ночной фон, ты поверх, акценты из `work/accents.json` (`kind: "night"` или `"light"` — на светлом за тобой мягкая тень) |

## Широкая запись из OBS

```
/reel-wide ~/Movies/Reels-wide-<дата>.mp4 [— бриф] [--slug name] [--speed 1.12]
```

Запись профилем OBS «Рилсы широкий 4104x1964» (слева твой макет с камерой, справа экран 1:1).
Без брифа действует постоянное ТЗ: все твои комментарии остаются, пустота (набор, ожидание, скролл,
бормотание) вырезается, под каждой фразой — тот момент экрана, о котором она, с зумами и подсветкой
слов; субтитры, 2–3 смены фона вокруг карточки камеры, звуки и тихая музыка. Без согласований на
середине: одна остановка — превью (обычное и ×1,12), «ок» — финал `renders/final.mp4` и
`renders/final.x1.12.mp4`. Если ключевое слово для директа не прозвучало, Claude спросит его в отчёте.

| Где | Что |
|---|---|
| `--speed` | ускорение второй версии превью и финала, по умолчанию 1.12 |
| `broll/screen.json` | что показывает окно: шоты, секунды записи под каждой фразой, зумы, подсветка и обводки |
| `broll/clips.json` | заголовки разделов, переходы окна, тексты смен фона и финала |
| `work/cuts.manual.json` | что вырезано руками (секунды записи и причины) |
| `scripts/ru/wide/` | скрипты формата: разведка записи, резы по огибающей, кадры окна, клипы, база с карточкой |

## Проверка сценария по принципам — `--principles`

По умолчанию выключена. Включается флагом `--principles` в `/remake`, `/remake-fast` и `/reel`
или словами «проверь сценарий по принципам» на готовом проекте. Восемь проверок: фраза продаёт
следующую, конкретика вместо обобщений, ценность против времени, петли любопытства, одно
возражение, понятно без контекста, вода, ритм кадра. Правила —
`.claude/skills/reel-remake/references/script-principles.md`.

Claude пишет `PRINCIPLES.md` в проект: по каждому принципу вердикт для этого сценария —
**✓ уместно**, **~ спорно** или **— не здесь** — и почему, ниже правки номерами «было → стало».
Сценарий не меняется, пока ты не ответишь номерами («бери 1 и 3») или «как есть».
Где отвечать: в `/remake` — на ГЕЙТЕ R, в `/remake-fast` — вместе с текстом до съёмки,
в `/reel` — на ГЕЙТЕ B (там речь уже снята: только вырезать, переставить или показать в кадре).
Цифры не выдумываются: нет источника — `[проверь: сколько?]`. Зритель берётся из `brand.md` →
«Зритель».

## Настройки одного рилса — `fx/fx.json`

**Картинка**

| Настройка | На что влияет | По умолчанию |
|---|---|---|
| `look` | стиль ролика: `"night"` — ночной интерфейс (ночной фон, ты вырезан, предметы-чертежи, 1–2 светлых акцента; субтитры сами тёмные, на светлом — светлые). Не путать с `looks` — живыми сменами образа на фразе | в быстром ремейке `"night"` (с 2026-10-26), иначе обычный стиль |
| `location_joins` | на каких стыках «рывок» со смазом | смены локаций |
| `camera` | наезды и дрейф: когда, насколько | по плану |
| `titles` | смена фона: тёмный фон, крупный текст за головой | 2–4 на рилс |
| `phone`, `thumbs` | телефон с исходником, плавающие превью | по сюжету |
| `world_swap` | «человек остаётся, мир меняется» на сменах локаций; `dur` — длина, с | все смены локаций, 0,32 |
| `impacts` | удар на слове: тряска, расслоение цвета, вспышка | на звуке `hit` (один на рилс) |
| `face.follow` | наезды идут к лицу | вкл |
| `face.eye_match` | на смене локации лицо не прыгает | вкл |
| `grade.match` | выравнивание цвета локаций: 0 выкл, 1 максимум | 0,7 |
| `grade.tint` | фиолетовый в тенях: 0 выкл | 0,5 |
| `grade.contrast` | мягкий контраст | 0,12 |
| `grade.grain` | зерно: 0 выкл | 2 |
| `looks` | живая смена образа на фразе: `moody` (мрачнее), `film` (плёнка, леттербокс; `wipe: "film"` — переход плёнкой), `bw` (ч/б) | нет |
| `textmask` | полный кадр: видео внутри гигантских букв (засечки); `stretch` вытягивает буквы | нет |
| `shrink` | кадр сжимается в телефон на тёмном фоне | нет |
| `relocate` | ты вырезан маской и опущен вниз (макушка на `head_top`, по умолчанию 0,57 высоты), за тобой твоя же комната — размытая (`bg_blur`), осветлённая (`lift`) и приглушённая (`sat`); верх кадра свободен под окно с графикой. Маски: `fx_picture.py --prep-relocate` | нет |
| `titles[].circle` | вместо смены фона кадр закрывается в круг вокруг лица | нет |
| `thumbs.behind` | плавающие превью уходят за спину (маски спикера) | нет |
| `camera` + `"ease"` | плавный отъезд из наезда («шире план») | линейно |

**Звук**

| Настройка | На что влияет | По умолчанию |
|---|---|---|
| `sfx` | эффекты на событиях: слово, вид, громкость | на каждом визуальном событии, тихо |
| `sfx_kit` | папка своих эффектов | `brand/sfx` |
| `sound.voice.chain` | обработка голоса; `"off"` — выкл | вкл |
| `sound.join_fade_ms` | сглаживание щелчков на склейках | 6 |
| `sound.music.src` | трек | нет |
| `sound.music.level_db` | громкость музыки в паузах: −12 громче, −18 тише | −15 |
| `sound.music.duck_db` | насколько тише музыка под голосом | −8 |
| `sound.music.stops` | стоп музыки перед фразой и возврат на слове | — |
| `audio.mix` | какой готовый звук идёт в видео | `fx/mix.wav` |

**Субтитры** — `PLAN.json` → `captions`: `hide` (где скрыть), `baseline_keys` (где поднять или опустить).

**Кинетические субтитры (для ремейков с окном над головой)** — `PLAN.json` → `captions.style: "kinetic"`:
по 1–3 слова между окном и головой, будущие слова приглушены, акцентное слово — курсив с засечками
(`font_serif.italic`) фиолетовым. В `captions.kinetic`: `accent_words` или `accent` (время слова) — акценты; `breaks` —
где начать новую группу; `y_keys` — высота центра строки (по умолчанию 1030); `theme_keys` —
`light` (тёмный текст на светлой стене) или `dark` (белый, для врезок и крупных планов); `theme_default` — тема
там, где ключей нет (по умолчанию `light`, в ночном стиле — `dark`).
В ночном стиле (`fx/fx.json` → `"look": "night"`) ключи тем ставятся сами: на светлых акцентах (`work/accents.json`, `kind: "light"`) и светлых полноэкранных врезках (`broll/plan.json`, `theme: "light"`) субтитры тёмные на светлом, потом снова белые; свои `theme_keys` в `PLAN.json` главнее.
Значения по умолчанию можно поменять в `brand.md` → `captions.kinetic`. Обычные субтитры не меняются.

**Окно над головой** — клипы графики на ките `scripts/ru/broll/screen-kit.js`: титр, иконки, окно
браузера с твоими скриншотами и записями экрана, подсветка, рамка, курсор, счётчик (`lead: 'hide'` —
без ведущих нулей), бейдж «N/5» в шапке окна (`win.pager`), список-хук «топ N» с размытыми именами и
звёздами (`list`), светлая полноэкранная карточка «Плагин номер N» (`mode: 'card'`). Собираются
`python3 scripts/ru/broll/build.py`, записи экрана режутся `node scripts/ru/broll/screen-frames.mjs`.
Ночная тема — `theme: 'night'`; сцены с предметами и акценты — `OK.run` (`scripts/ru/broll/object-scene.js`), предметы — `scripts/ru/broll/object-kit.js` (список из 32 в шапке).

## Где результат

`renders/final.mp4` — утверждённый. Новые варианты кладутся рядом (`final.v2.mp4`,
`final.sound-A.mp4`), старые не затираются.
