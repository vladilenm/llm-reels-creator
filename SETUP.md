# SETUP — где какие настройки

Проще всего менять словами: «музыку тише», «убери зерно». Claude сам поправит нужный
файл. Эта шпаргалка нужна, чтобы понимать, где что лежит и на что влияет.

Два уровня:
- **Бренд** (`brand/`) — действует на все рилсы.
- **Рилс** (`video-projects/<дата-слаг>/`) — только на один ролик.

`lessons.md`, `refs/NOTES.md` и `brand/music/tracks.json` — твои локальные файлы, в гит не
попадают. `brand/brand.md` лежит в гите (репозиторий приватный). `npm run setup` (или первый
`/reel`) создаёт недостающие из шаблонов `*.example`. Меняй свой файл, шаблон не трогай.

## Запуск рилса

```
/reel <файл> — бриф одной строкой [--mode kit|full] [--density light|medium|heavy] [--review-cuts] [--principles]
```

| Флаг | Что |
|---|---|
| `--mode kit` | по умолчанию: монтаж, графика, субтитры, превью |
| `--mode full` | сразу готовый MP4 |
| `--density` | сколько графики: light 2–4 в минуту, medium 4–7, heavy почти на каждой фразе |
| `--review-cuts` | показать список вырезанного до сборки |
| `--principles` | проверить речь по принципам удержания (см. ниже); выключено по умолчанию |

Паузы между фразами — 0,08 с, по громкости звука, а не по словам расшифровки (`scripts/ru/wide/env-cuts.py`,
`--keep`). Видео начинается сразу со слова. Ускоренная версия превью и финала — по плотности речи: 3,45 ÷ слов
в секунду, от ×1,05 до ×1,12 (плотный текст — ×1,05); скажешь своё число — будет оно.

Светлый стиль, OBS-дубль (камера-карточкой снизу): на ровной стене без мебели смены фона идут с маской — комната и рамка
карточки уходят, ты на тёмном фоне (`scripts/ru/wide/obs_swaps.py`); если у плеча кресло — без маски,
темнеет всё вокруг карточки.

**Дополнительная чистка для старых проектов** (`build-edl --envelope -55`). Основной способ —
`env-cuts.py` выше; два автоматических прохода чистки пауз вместе не запускаются. Whisper растягивает слова
в тишину, поэтому паузы меряются по громкости: всё тише −55 дБ — тишина, и любая пауза от 0,12 с —
внутри фразы или на склейке — ужимается до 0,05 с тишины с каждой стороны от речи. Начало и хвост
ролика не трогаются.

| Настройка `build-edl` | На что влияет | По умолчанию |
|---|---|---|
| `--envelope` | включает дополнительный проход по громкости; значение — порог тишины, дБ | выключен; при использовании −55 |
| `--env-min` | паузы короче не трогаются, с | 0,12 |
| `--env-keep` | сколько тишины оставить у речи с каждой стороны, с | 0,05 |
| `--env-check` | порог проверки: что ещё слышно как паузу (тихие хвосты, вдохи), дБ | −42 |

После чистки — `work/pauses.remaining.md`: паузы, которые ещё слышны при −42 дБ, с готовым резом
каждой, и «тихие слова в резах» — слова, которые whisper поставил на вдох (их надо поправить, иначе
они выпадут из субтитров). Скажи «режь и эти паузы» — Claude добавит их в резы и пересоберёт.

## Дубль из OBS

Для ночного ремейка остаётся сборка `night_base.py`. Светлый OBS-дубль обрабатывает `obs_relocate.py`:
если снимаешь через свою сцену OBS (ровный фон, камера скруглённой карточкой снизу, сверху заглушки
шаблона), Claude это видит сам (`obs_relocate.py --detect`, в ремейке — `footage-check`). По умолчанию
карточка остаётся на месте, а всё вокруг закрывает фирменный фон `canvas`, на склейках внутри карточки
наезд 1,00 ↔ 1,07. Вырезать тебя маской (relocate) — только по твоему выбору на превью: маска мигала на
спинке кресла. Скрипт: `python3 scripts/ru/fx/obs_relocate.py <проект>`.

| Настройка | На что влияет | По умолчанию |
|---|---|---|
| `--look` | `card` — карточка на фоне; `relocate` — ты вырезан, растянут на всю ширину, за тобой твоя размытая осветлённая комната | `card` |
| `--zoom` | наезд на склейках: два масштаба по очереди; финальный кусок без наезда | 1,0 и 1,07 (relocate: 1,0 и 1,05) |
| `--zoom-gap` | наезд меняется не чаще раза в N с (когда склейки в паре кадров друг от друга) | 0 — на каждой склейке |
| `--head-top` | relocate: где макушка, доля высоты кадра | 0,586 (≈ 59 %) |
| `--scale` | relocate: во сколько раз растянуть карточку (меньше ширины кадра не бывает) | 1,1 |
| `--card x0,y0,x1,y1,r` | задать карточку вручную, если не нашлась | ищется по кадру |
| `--masks` | только маски для смены фона за головой (после того как в `fx.json` добавлены `titles`) | — |

Карточка ищется автоматически. В relocate верх головы достраивается, если волосы упираются в край
карточки. Что получилось, записано в `renders/clean.obs.json`.

## Повторить чужой рилс

```
/remake <файл чужого рилса> — бриф: тема, что оставить, что поменять [--slug name] [--principles]
```

Claude разбирает рилс (сюжет, хук по кадрам, ритм, графика, съёмка, звук по цифрам),
пишет текст под тебя и план съёмки по локациям и ждёт «да» (ГЕЙТ R). Всё лежит в
`video-projects/<дата>-remake-<слаг>/`: `BREAKDOWN.md` — разбор, `SCRIPT.md` — сценарий,
`SHOOT.md` — карточка для съёмки. Факты, которых Claude не знает про тебя, помечены
`[проверь]`. Кадры, звук и текст чужого рилса в твой ролик не попадают.

Снял — запусти обычный монтаж со сценарием:

```
/reel inbox/<файл> --remake video-projects/<дата>-remake-<слаг>
```

| Флаг | Что |
|---|---|
| `/reel … --remake <проект>` | сценарий ремейка — основа для чистки (дубли) и плана графики |

## Быстрый ремейк

```
/remake-fast <файл чужого рилса> — бриф [--principles] [--audiences "программисты; маркетологи; предприниматели"]
```

`--audiences` — один контент под несколько целевых групп (по умолчанию выключено, можно и словами: «под три
аудитории»). В `SAY.md` своё начало под каждую группу (кто ты → боль → «нашёл, как…, а в конце скажу…») и одно общее
тело. Снимаешь одним дублем: все начала подряд с паузой 2 с, потом тело один раз. На выходе отдельный рилс на группу
(`video-projects/<дата>-<слаг>-a`, `-b`, `-c`) с одинаковой музыкой, звуками и скоростью и своя подпись к каждому.
Группы и угол называешь ты; не назвал — Claude предложит 2–3 вместе с текстом.

Без согласований на середине: Claude сразу отдаёт `SAY.md` — что говорить (🎧 — фразы, где тебя
закрывает врезка: их можно читать с листа) и `SCREEN.md` — что записать с экрана и куда кликать.
Вопросы «проверь» Claude решает сам и перечисляет решения. Снял — клади всё в `inbox/<слаг>/` и
запусти `/remake-fast video-projects/<дата>-remake-<слаг>`: дальше превью (обычное и ускоренное),
«да» — финал, ускоренная версия (`renders/final.x<F>.mp4`, скорость как на одобренном превью) и текст для
Instagram (`CAPTION.md`).
Ремейки с OBS-дублем идут в ночном стиле (`fx/fx.json` → `"look": "night"`): ночной фон, ты вырезан маской (кресло или мебель у плеча — карточка камеры на ночном фоне), предметы-чертежи, 1–2 светлых акцента; к превью — таблица движений `MOTION.md`. Старый светлый вид — по просьбе («как раньше, светлый»).

| Скрипт | Что |
|---|---|
| `node scripts/ru/footage-check.mjs <проект ремейка>` | что отснято против `SCREEN.md`, где дубль, высоко ли голова (тогда `relocate`), снят ли дубль через OBS (`layout: "obs"`; светлый вид — `obs_relocate.py`, ночной — `night_base.py`) |
| `node scripts/ru/speed-variant.mjs <проект> --factor 1.1` | ускоренная копия готового рилса (картинка, графика, субтитры и звук вместе) |
| `python3 scripts/ru/wide/gaps.py <проект> [t0-t1 …]` | звук без слов в расшифровке (щелчки, кашель, пропущенные дубли) и дорасшифровка выбранных фраз → `work/GAPS.md` |
| `python3 scripts/ru/wide/obs_swaps.py <проект> --prep`, затем без флага | Светлый стиль: смены фона с маской для OBS-дубля — маски, тёмный слой с текстом, ты поверх |
| `node scripts/ru/motion-check.mjs <проект>` | раскадровка движений: `PLAN.json` → `motion`, записи `{at, word, verb, what}` (время в секундах, слово из расшифровки, глагол, что в кадре; 16 id глаголов перечислены в начале `scripts/ru/motion-check.mjs`). Глагол не два раза подряд, не меньше пяти разных, 1–2 светлых акцента → `MOTION.md` |
| `python3 scripts/ru/wide/night_base.py <проект> --prep`, затем `--stills 1.0,4.6` и `--mix` (`--card` — без маски; `--allow-missing` — не останавливаться, если больше 5 % кадров без своей маски; `--until 20.66` — база только до этого времени (кусок)) | ночная база картинки: маски, ночной фон, ты поверх, акценты из `work/accents.json` (`kind: "night"` или `"light"` — на светлом за тобой мягкая тень); клипы `broll/plan.json` с `"layer": "back"` — за тобой |

## Широкая запись из OBS

```
/reel-wide ~/Movies/Reels-wide-<дата>.mp4 [— бриф] [--slug name] [--speed 1.12]
```

Запись профилем OBS «Рилсы широкий 4104x1964» (слева твой макет с камерой, справа экран 1:1).
Без брифа действует постоянное ТЗ: все твои комментарии остаются, пустота (набор, ожидание, скролл,
бормотание) вырезается, под каждой фразой — тот момент экрана, о котором она, с зумами и подсветкой
слов; субтитры, 2–3 смены фона вокруг карточки камеры, звуки и тихая музыка. Без согласований на
середине: одна остановка — превью (обычное и ×1,12), «ок» — финал `renders/final.mp4` и
`renders/final.x1.12.mp4`. Если ключевое слово для директа не прозвучало, Claude спросит его в отчёте.

| Где | Что |
|---|---|
| `--speed` | ускорение второй версии превью и финала, по умолчанию 1.12 |
| `broll/screen.json` | что показывает окно: шоты, секунды записи под каждой фразой, зумы, подсветка и обводки |
| `broll/clips.json` | заголовки разделов, переходы окна, тексты смен фона и финала |
| `work/cuts.manual.json` | что вырезано руками (секунды записи и причины) |
| `scripts/ru/wide/` | скрипты формата: разведка записи, резы по огибающей, кадры окна, клипы, база с карточкой |
| `obs_base.py --mask` | ты вырезан маской из стены и стоишь на фирменном фоне без карточки, в сменах фона крупный текст за головой (`fx/swaps.json`). Только для дубля у ровной стены без мебели у плеча: кресло маска цепляет, тогда без флага — карточкой |

## YouTube: сцена и лицо (длинные видео)

```
node scripts/long/face-plan.mjs video-projects/<слаг>/transcript.words.json --out video-projects/<слаг>/FACE.json
node scripts/long/face-plan.mjs --check video-projects/<слаг>/FACE.json --transcript video-projects/<слаг>/transcript.words.json
```

Как пользоваться (записать, запустить, править): `docs/YOUTUBE.md`. Отдельный флоу для YouTube 16:9, рилсы он не трогает. Одна тёмная сцена на весь ролик, на ней по одной
мысли за раз; лицо то в узкой плашке справа, то на весь кадр на личных репликах. Запуск целиком: `/youtube <файл> [— бриф]` — расшифровка, чистка, проверка фактов
по источникам (`FACTS.md`), план карточек с образами, превью; после твоего «ок» — финал. Звук по умолчанию только голос: без музыки, эффектов и
вшитых субтитров; музыку и звуки включаешь флагом проекта.

| Где | Что |
|---|---|
| `style-library/03-vladilen-stage/tokens.css` | цвета, шрифты, размеры, плашка лица, движение: всё из дизайн-системы, размеры × 2 для 1080p |
| `style-library/03-vladilen-stage/DESIGN.md` | правила стиля: что делать и чего нет |
| `scripts/long/face-lexicon.json` | по каким фразам лицо выходит на весь кадр: вопросы, личные реплики, выводы, смена раздела, финал; русский и английский, правится словами |
| `--hook 2.0` | сколько секунд хук держится на лице |
| `--share 0.07` | сколько ролика (7 %) занимают обычные выходы лица на весь кадр |
| `--min-gap 11`, `--max-gap 75` | не чаще раза в 11 с и не реже раза в 75 с |
| `--dock-crop x,y,w,h` | кроп записи для плашки (доли кадра); по умолчанию по центру |
| `FACE.json` | план лица: правится руками, потом `--check`; участки без лица (`none`) ставятся только вручную |
| `style-library/03-vladilen-stage/cards/stage/` | карточки сцены: цитата, термин, документ, шаги, сравнение, цифра, схема, чат, образ, плитки, иллюстрация/скриншот на всю сцену (`figure`); слова-подсказки — `data-at` (секунда появления), тексты — слоты из `style.json` |
| `style-library/03-vladilen-stage/icons/icons.js` | свои линейные иконки для образов и плиток (агент, терминал, телефон, коробка, мишень…); новую иконку дорисовывают в том же стиле |
| `assets/logos/` проекта | настоящие логотипы продуктов, о которых говоришь (ChatGPT, Claude, Meta…): с официального сайта или Wikimedia Commons; в плане вместо имени иконки пишется путь к файлу |
| `node scripts/long/web-shot.mjs <url> --out <проект>/assets/web/<имя>.png --phrase "…"` | скриншот найденного источника: прячет баннеры, ничего не принимает, рядом пишет `<имя>.json` с доменом и местом фразы; в ролике окно браузера, наезд на фразу и подсветка |
| `mkill.mjs` проекта | полноэкранные иллюстрации проекта (svg из иконок и цветов стиля, библиотека `scripts/long/lib/ill.mjs`), идут в карточку `figure` с меткой «ИЛЛЮСТРАЦИЯ» |
| `FACTS.md` | проверка фактов речи: что сказано, верно ли, источник, что показать на экране |
| `CARDS.json` | план карточек: какая карточка, на какой фразе начинается и кончается, тексты слотов, на каких словах что появляется; формат в навыке `stage-cards` |
| `node scripts/long/stage-assemble.mjs <проект> --check` | проверка плана до рендера; `--preview --review` — быстрая сборка 960×540 и листы кадров вокруг склеек; `--final` — 1920×1080; клипы карточек кэшируются, правка `FACE.json` их не перерисовывает |
| `node scripts/long/check-stage-cards.mjs` | проверка карточек: текст на максимальной длине, повторяемость кадра, размеры шрифтов; `--poster` обновляет постеры, `--hyperframes` добавляет проверки фреймворка |

## Проверка сценария по принципам — `--principles`

По умолчанию выключена. Включается флагом `--principles` в `/remake`, `/remake-fast` и `/reel`
или словами «проверь сценарий по принципам» на готовом проекте. Восемь проверок: фраза продаёт
следующую, конкретика вместо обобщений, ценность против времени, петли любопытства, одно
возражение, понятно без контекста, вода, ритм кадра. Правила —
`.claude/skills/reel-remake/references/script-principles.md`.

Claude пишет `PRINCIPLES.md` в проект: по каждому принципу вердикт для этого сценария —
**✓ уместно**, **~ спорно** или **— не здесь** — и почему, ниже правки номерами «было → стало».
Сценарий не меняется, пока ты не ответишь номерами («бери 1 и 3») или «как есть».
Где отвечать: в `/remake` — на ГЕЙТЕ R, в `/remake-fast` — вместе с текстом до съёмки,
в `/reel` — на ГЕЙТЕ B (там речь уже снята: только вырезать, переставить или показать в кадре).
Цифры не выдумываются: нет источника — `[проверь: сколько?]`. Зритель берётся из `brand.md` →
«Зритель».

**Субтитры** — `PLAN.json` → `captions`: `hide` (где скрыть), `baseline_keys` (где поднять или опустить).

**Кинетические субтитры (для ремейков с окном над головой)** — `PLAN.json` → `captions.style: "kinetic"`:
по 1–3 слова между окном и головой, будущие слова приглушены, акцентное слово — курсив с засечками
(`font_serif.italic`) фиолетовым. В `captions.kinetic`: `accent_words` или `accent` (время слова) — акценты; `breaks` —
где начать новую группу; `y_keys` — высота центра строки (по умолчанию 1030); `theme_keys` —
`light` (тёмный текст на светлой стене) или `dark` (белый, для врезок и крупных планов); `theme_default` — тема
там, где ключей нет (по умолчанию `light`, в ночном стиле — `dark`).
В ночном стиле (`fx/fx.json` → `"look": "night"`) ключи тем ставятся сами: на светлых акцентах (`work/accents.json`, `kind: "light"`) и светлых полноэкранных врезках (`broll/plan.json`, `theme: "light"`) субтитры тёмные на светлом, потом снова белые; свои `theme_keys` в `PLAN.json` главнее.
Значения по умолчанию можно поменять в `brand.md` → `captions.kinetic`. Обычные субтитры не меняются.

**Окно над головой** — клипы графики на ките `scripts/ru/broll/screen-kit.js`: титр, иконки, окно
браузера с твоими скриншотами и записями экрана, подсветка, рамка, курсор, счётчик (`lead: 'hide'` —
без ведущих нулей), бейдж «N/5» в шапке окна (`win.pager`), список-хук «топ N» с размытыми именами и
звёздами (`list`), светлая полноэкранная карточка «Плагин номер N» (`mode: 'card'`). Собираются
`python3 scripts/ru/broll/build.py`, записи экрана режутся `node scripts/ru/broll/screen-frames.mjs`.
Ночная тема — `theme: 'night'`; сцены с предметами и акценты — `OK.run` (`scripts/ru/broll/object-scene.js`), предметы — `scripts/ru/broll/object-kit.js` (список из 32 в шапке).
