# Сценарий: «Этот рилс смонтировал Claude»

Формат — по `refs/ref-03.mp4` (разбор в `refs/NOTES.md`). Текст свой, не перевод.
Палитра и шрифт — из `brand/brand.md` (Inter, `#0E0B14` + `#B79CFF`). Без ротоскопии.
CTA — `cta_default`. Цель ~50 с.

Факты в тексте проверяемы на этом же прогоне. `[сырое]` и `[итог]` — хронометраж
исходника и готового рилса; вписываются после монтажа, не заранее.

## Локации

Снимать вертикально, каждую фразу блока целиком в своей локации, между фразами
пауза 1–2 с (её вырежет cut-silences). Можно по 2–3 дубля — лишние уберёт cut-mistakes.

| Код | Локация |
| --- | --- |
| L1 | За столом, крупно, по грудь |
| L2 | Общий план комнаты, сидя |
| L3 | Третья точка: другой угол / на полу / у окна |
| L4 | Тёплый свет (лампа, свечи), крупно |
| L5 | Очень крупно у микрофона или камеры |
| L6 | В полный рост, стоя |

## Что проверить до съёмки

- Бит 8 работает, только если правку «опусти субтитры» на этом рилсе реально
  применяем — сделаем её живым эффектом, не фейком: в монтаже субтитры до фразы
  выше, после — ниже.
- Бит 10: панель — скрин настоящего плана (ГЕЙТ B), а не макет.
- Ник для CTA: вписать.
