# Музыка для рилсов

Сюда кладутся треки, которые можно использовать коммерчески: из твоей подписки на сток
или сгенерированные. Аудиофайлы в git не попадают (`*.mp3`, `*.wav` в `.gitignore`), в
репозитории остаются только этот файл и `tracks.json`.

## Фирменная библиотека (с 2026-10-26)

Треки собираются автоматически и отбираются на слух:

1. `node scripts/ru/music-fetch.mjs` — кандидаты из Openverse (Jamendo, Freesound, ccMixter), только CC0 и CC BY.
2. `python3 scripts/ru/music_screen.py` — отсев по замерам (темп, вступление, ровность, полоса голоса).
3. `python3 scripts/ru/sound_review.py build` и `serve` — страница: каждый трек отдельно и под твоим голосом.
4. `python3 scripts/ru/sound_review.py apply` — отмеченные «беру» скачиваются целиком и попадают в `tracks.json`
   со строкой автора; «нет» больше не появятся (`rejected.json`).

Трек под рилс выбирает `node scripts/ru/music-pick.mjs <рилс> --mood <настроение>`.

## Как добавить трек

1. Положи файл сюда: `brand/music/<имя>.mp3`.
2. Допиши его в `tracks.json`: настроение, BPM (если знаешь), откуда трек и какая у него
   лицензия. Без лицензии трек в рилс не идёт.

```json
{ "file": "calm-tech-100.mp3", "mood": ["спокойный", "технологичный"], "bpm": 100,
  "source": "Artlist", "license": "коммерческое использование, подписка до 2027-06" }
```

BPM — подсказка для сетки битов (`music-grid.mjs` ищет темп в пределах ±6 %). Если не
знаешь, оставь `null`, тогда я замерю темп сам перед монтажом.

## Как трек попадает в рилс

`scripts/ru/fx/sound.py` (стадия S4c) берёт трек из `fx/fx.json` → `sound.music.src`,
сам подбирает смещение, чтобы ключевые моменты рилса легли на доли, приглушает музыку
под речью и делает стоп перед панчлайном с возвратом на сильную долю. Подходящий
темп для рилса подсказывает `python3 scripts/ru/fx/sound.py <project> --suggest-bpm`.
