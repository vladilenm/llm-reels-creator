Запусти скилл `remake-fast` и веди цикл строго по `.claude/skills/remake-fast/SKILL.md`.

Аргументы: $ARGUMENTS

- Файл чужого рилса (обычно в `inbox/`) → F1: разбор, сценарий, `SAY.md` (что говорить, 🎧 — где тебя
  не видно и можно читать), `SCREEN.md` (что записать с экрана). Остановка: «снимай».
- `--principles` — проверить сценарий по принципам удержания (`.claude/skills/reel-remake/references/script-principles.md`): вердикт по каждому принципу «уместно / спорно / не здесь» и правки номерами вместе с текстом; отвечаю номерами или «снимаю как есть». По умолчанию выключено; правки вносятся только те, что я выберу.
- `--audiences "программисты; маркетологи"` — один контент под несколько целевых групп: своё начало под каждую
  аудиторию над общим телом, снимаю одним дублем, на выходе по рилсу на группу (`<date>-<slug>-a`, `-b`…). Группы
  и угол называю я; не назвал — Claude предлагает 2–3 вместе с текстом. По умолчанию выключено.
- Проект ремейка (`video-projects/<date>-remake-<slug>`) → F2: отснятое из `inbox/<slug>/` → превью.
  Остановка: «ок или правки?».
- «да» на превью → F3: финал, версия ×1,1, текст для Instagram.
- Без ГЕЙТОВ R, A, B: вопросы «проверь» решай сам и перечисляй решения в отчёте.
- Кадры, звук и текст референса в рилс не попадают. Ничего не публикуй.
