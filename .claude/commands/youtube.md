Запусти скилл `vladilen-youtube` для этой записи и веди его по стадиям Y0–Y8 строго по
`.claude/skills/vladilen-youtube/SKILL.md`.

Аргументы: $ARGUMENTS

- Первый аргумент — путь к сырому файлу (обычно `~/Movies/YouTube-*.mp4`). Текст после `—` — бриф.
- По умолчанию одна остановка — превью (Y7). `--review-plan` добавляет остановку на плане карточек (Y5).
- Факты из речи проверяются по источникам (Y4, `FACTS.md`); на экране только подтверждённое, с подписью источника.
- Если проект уже существует — продолжи с первой стадии без результата, без повторных платных вызовов.
