description: Рилс из широкой OBS-записи (макет + экран): вся речь, экран под слова, превью → «ок» → финал (Reels Studio)
argument-hint: <Reels-wide-*.mp4> [— бриф одной строкой] [--slug name] [--speed 1.12]
---

Запусти скилл `reel-wide` и веди рилс по стадиям W0–W8 строго по `.claude/skills/reel-wide/SKILL.md`
(движок — `vladilen-reels`).

Аргументы: $ARGUMENTS

- Первый аргумент — широкая запись из OBS (`~/Movies/Reels-wide-*.mp4`, 4104×1964: слева макет с камерой,
  справа экран 1:1). Текст после `—` — бриф; без него действует постоянное ТЗ из скилла.
- Вся речь остаётся, пустота (набор, ожидание, скролл, бормотание) вырезается, под каждой фразой —
  тот момент экрана, о котором она, с зумами и подсветкой; субтитры, смены фона, звуки и музыка.
- Без ГЕЙТОВ A и B: решения перечисли в отчёте. Одна остановка — превью (обычное и ×1,12): «ок или правки?».
- «ок» → финал `renders/final.mp4` и `renders/final.x1.12.mp4` (`--speed` меняет ускорение), check-reel PASS.
- Если проект уже есть — продолжи с первой незавершённой стадии, без повторных платных вызовов. Ничего не публикуй.
