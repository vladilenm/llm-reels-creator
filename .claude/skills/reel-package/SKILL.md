# reel-package — подпись и обложка к готовому рилсу

Вход: проект рилса `video-projects/<date>-<slug>/` с готовым финалом (`renders/final*.mp4`) и
`transcript.clean.json`. Выход: `CAPTION.txt` и `cover/cover.png` (+ `cover.grid45.png`). Ничего не публикуется.

```
/reel-package <проект> [— бриф: о чём подпись, текст плашки, цвет, объект] [--no-object] [--purple]
```

Без проекта — самый свежий `video-projects/*` с `renders/final*.mp4`. Вопросов по ходу не задавать;
одна остановка — перед платной генерацией объекта (шаг 3).

## Перед работой

- `~/.agents/brand/voice.md` — голос, позиции, формат призыва.
- Проект: `transcript.clean.json` (что реально сказано), `PLAN.json` (хук, факты в `events[].facts`),
  `BRIEF.md`, `lessons.md` (раздел этого рилса). Если есть `FACTS.md` или проверенные источники в
  отчётах прогона — брать факты оттуда.
- Референс обложки: `refs/cover-ref-01.webp` (локальный, в git не попадает). Если файла нет — стиль ниже.

Правило фактов то же, что в рилсе: ни одной цифры, даты или цитаты, которой нет в речи, у заказчика или в
проверенном источнике. Если речь и источник расходятся («до конца года» против «в этом или следующем
году»), в подписи и на плашке — версия источника.

## 1. Подпись (CAPTION.txt)

Скилл `ig-caption` (линтер `~/.claude/skills/ig-caption/caption.py`). Рилс сам несёт хук, поэтому
работа «A»:

- Строка 1 (≤ 125 символов, видна до «ещё»): конкретика (имя, цифра, год) + один вопрос-призыв в
  комментарии. Не приветствие, не хэштег, не эмодзи первым символом.
- 3–5 коротких абзацев его голосом: новость/наблюдение → его разворот («я не сторонник…, но заметил…») →
  вывод/шутка из финала рилса. Пересказ речи, а не новый текст: его формулировки, правка только по фактам.
- Поисковые фразы (2–3) обычными словами в тексте: имя героя, термин, тема. Передать их линтеру.
- Призыв ровно один. Кодовое слово — только если он сказал его в кадре; иначе вопрос в комментарии.
- Без ссылок. Эмодзи — только если в `voice.md` разрешены. Хэштеги: 0–3, тематические, в конце.
- Музыка с `credit` в `fx/fx.json` → строка указания автора в конце. Нет `credit`, а лицензия трека
  неизвестна — сказать в отчёте.

```bash
python3 ~/.claude/skills/ig-caption/caption.py $P/CAPTION.txt --keywords "фраза 1,фраза 2,фраза 3"
```

Линтер не понимает русский: кириллические хэштеги считает за 0, призыв «пишите в комментах» не видит.
Эти два WARN объяснить в отчёте, остальные FAIL/WARN исправить. Прогнать текст по `ig-human`-правилам:
без длинных тире-разворотов, «не X, а Y» подряд, канцелярита.

## 2. Обложка — кадр и плашка (бесплатно)

Стиль референса: крупное лицо в верхней половине, плашка на груди — насыщенный красный прямоугольник со
скруглением, белый жирный капс с тонкой тёмной обводкой, наклон-курсив и поворот −3°; 1–3 строки по
2–3 слова; под плашкой — глянцевый 3D-предмет, который зритель считывает за долю секунды (кольца, пачка
денег, знак). Лицо — всегда настоящий кадр из рилса, никогда не генерация.

```bash
python3 scripts/ru/cover/make_cover.py $P --frames 0.4,1.1,4,14.5,26.5,33.2   # cover/candidates.png
```

Выбрать кадр сам: глаза открыты, выразительный жест (рука у виска, раскрытые ладони), рот не в
середине слова, лицо резкое. Время берётся из `renders/picture.mp4` (с цветом монтажа), не из
финала (там открывающий зум).

Текст плашки: суть хука рилса в 2 строках, вопрос или обещание, без кликбейта из `brand.md`
(«тебе врали», «никто не говорит»). Цвет: `red` по референсу; `--purple` или бриф → `purple` (бренд).

`$P/cover/cover.json` (схема в шапке `make_cover.py`), затем:

```bash
python3 scripts/ru/cover/make_cover.py $P      # cover/cover.png, .grid45.png, .sheet.png
```

Посмотреть `cover.sheet.png` (слева 9:16, справа сетка профиля 4:5): плашка и объект целиком в сетке,
плашка не режет подбородок и рот, нет WARN.

## 3. Объект — Higgsfield (платно, после «да»)

Предмет — символ темы, одна вещь (знак радиации, рубильник, сервер, пачка денег, логотип-значок).
Модель `gpt_image_2_5`, `--aspect_ratio 1:1 --resolution 2k`, на чистом чёрном фоне. Промпт по шаблону:

```
Glossy 3D <object> as a thick enamel/metal object, slight tilt toward camera, soft studio rim light,
photorealistic product render, isolated on pure black background, no text
```

Перед генерацией собрать обложку без объекта, показать её, промпт и цену
(`higgsfield generate cost gpt_image_2_5 --prompt "…" --aspect_ratio 1:1 --resolution 2k`, обычно
0,5 кредита) и ждать «да». Проверить `higgsfield account status`; если не авторизован — попросить
его выполнить `higgsfield auth login`. После «да»:

```bash
higgsfield generate create gpt_image_2_5 --prompt "…" --aspect_ratio 1:1 --resolution 2k --wait
curl -sSL -o $P/cover/object.png "<url>"
python3 scripts/ru/cover/make_cover.py $P --cut $P/cover/object.png   # → cover/object-cut.png
```

Вписать `"object": "cover/object-cut.png"` в `cover.json`, собрать заново, посмотреть лист. Предмет с
чёрными краями (обод, тень) вырезается по фону от углов — проверить, что края не съедены.
`--no-object` или «без объекта» — шаг пропускается.

## Отчёт

Коротко: подпись целиком в блоке для копирования, квитанция линтера (видимая часть, призыв, хэштеги,
поисковые фразы), путь к обложке и листу, сколько кредитов ушло. Что решено, что на его выбор
(цвет плашки, другой текст — пересборка бесплатная). Не публиковать и не отправлять.
