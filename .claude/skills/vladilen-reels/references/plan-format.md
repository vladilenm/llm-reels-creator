# Формат плана графики (S3 → S4)

Все времена — секунды на **чистом** таймлайне (`transcript.clean.json`,
`renders/clean.mp4`).

## PLAN.json (читают скрипты: контакт-листы берут из него времена событий)

```json
{
  "hook": { "variant": "B", "first_words": "Агенты экономят часы каждую неделю", "frame0": "…", "by_3s": "…" },
  "density": "medium",
  "cta": "Подписывайся — разбираю AI и фронтенд без воды",
  "events": [
    {
      "id": "01-hours",
      "in": 4.30,
      "out": 7.90,
      "type": "full",
      "phrase": "экономят часы каждую неделю",
      "anchor_word": { "text": "часы", "at": 5.12 },
      "shows": "Карточка «часы в неделю» с относительной шкалой, без цифр",
      "reason": "Обещание хука нужно показать, а не только сказать",
      "facts": []
    }
  ]
}
```

- `type`: `full` (полноэкранная врезка, лица нет), `panel` (панель рядом с лицом,
  прозрачная), `card` (карточка поверх, прозрачная, маленькая), `none` (оставить лицо —
  записывать, если отказ от графики осознанный).
- `anchor_word.at` — время слова из `transcript.clean.json`; главное изменение клипа
  ставится на него (допуск ±2 кадра).
- `facts` — любые цифры/факты на экране с источником (`"речь 0:12"`, `"бриф"`). Пусто —
  значит на экране нет цифр.

## PLAN.md (для человека, показывается на ГЕЙТЕ B)

```
| # | In–Out | Фраза | Тип | Что на экране, на каких словах | Почему |
```

Плюс три варианта хука (что на кадре 0, какие первые слова, что меняется к 3 с) и
рекомендация.

## broll/plan.json (S4, схема motion-broll — читают assemble.mjs и make_pages.py)

```json
{ "title": "…", "video": "../renders/clean.mp4", "fps": 30,
  "clips": [ { "id": "01-hours", "title": "Часы", "line": "экономят часы каждую неделю",
               "in": 4.30, "out": 7.90, "kind": "full", "file": "01-hours.mp4" } ],
  "notes": ["Шкала относительная: цифр в речи нет"] }
```

`kind`: `full` → `.mp4`; `panel` (и наш `card`) → `.mov` с альфой. `file` — путь
относительно `broll/`.
