# Formats · BREAKDOWN.md, SCRIPT.md, SHOOT.md

All three are in Russian, short and concrete. Times are the reference's seconds
(`0:05,5`). A worked example of the whole set: `refs/ref-04.md` + `refs/ref-04-text.md`.

## BREAKDOWN.md — what the reference does and why it works

```markdown
# Разбор · <slug>

Источник: `assets/ref.mp4` (56,8 с, 720×1280, 30 fps, англ.). Разбор по кадрам 2 fps,
расшифровке и вшитым субтитрам.

## Паспорт
| | |
|---|---|
| Длительность | 56,8 с, 148 слов, 2,6 слова/с |
| Планы | 10 склеек, медиана 5,8 с; локаций 7 |
| Первое слово | 0:00,2 |
| Звук (по цифрам) | громкость −16 дБ; в паузах −52 дБ → музыки под голосом нет |

## Сюжет в одну строку
«я не монтировал → одна фраза = монтаж → доказательство ×3 → моё отличие → CTA»

## Биты
| Бит | Время | Задача | Как сделано |
|---|---|---|---|
| Хук | 0:00–0:03 | остановить скролл | … |
| Обещание | … | | |
| Доказательства | … | | |
| Поворот | … | | |
| CTA | … | | |

## Хук по кадрам
- кадр 0: … (что видно без звука)
- к 1 с: …
- к 3 с: … — почему досматривают

## По времени
| Время | Фраза (оригинал → смысл по-русски) | Что в кадре | Приём |
|---|---|---|---|

## Ритм
Смена локации каждые …; графика на …% фраз; лицо открыто …; полноэкранных врезок без
лица N, каждая ≤ … с.

## Визуальная система
Палитра (hex на глаз), шрифты (засечки / гротеск / моно), субтитры (где, размер,
подложка, активное слово), фактуры, повторяющиеся элементы.

## Съёмка
Локации и крупности, камера (штатив / с рук), свет, одежда и реквизит, взгляд, жесты.

## Почему держит внимание
3–5 механик: каждая — что именно и в какой момент.

## Приёмы и наш пайплайн
| Приём | У нас | Чем |
|---|---|---|
| Текст за головой | есть | `fx.json` titles + маски |
| Чек-инструкция | собрать | карточка motion-broll |
| Скрины чужих рилсов | не берём | чужой контент |

Звук мной не прослушан: громкость, музыку и склейки по интонации проверь на слух.
```

## SCRIPT.md — the adapted script (the backbone for /reel)

```markdown
# Сценарий · <slug>

Референс: `BREAKDOWN.md`. Цель ~55 с, ~140 слов (темп Владилена 2,5 слова/с).
Решения заказчика: … (дата)

## Берём / меняем
| Берём | Меняем | Почему |
|---|---|---|

## Хук
- Основной (как у референса): кадр 0 — …; к 1 с — …; к 3 с — …
- Запасной: …

## Локации
| Код | Где | Крупность | Зачем |
|---|---|---|---|
| L1 | за столом, комната за спиной | по грудь | база: хук, утверждения |

## Текст
| # | Лок. | Фраза | Что в кадре | На каком слове |
|---|---|---|---|---|
| 1 | L1 | Я не смонтировал ни секунды этого ролика. | «НЕ МОНТИРОВАЛ» за головой | «не», «секунды» |

## Проверь
- [проверь: «15 минут» — это твоё время на рилс? Если нет, какое?]

## Собрать нового
1. … — эффект, где в рилсе, сколько работы.
```

Rules: one sentence per row; «Что в кадре» names only things we can really show
(our files, our screen, our past reels); every number in a phrase is either confirmed
or under «Проверь». The `#` numbers are shared with SHOOT.md.

## SHOOT.md — the card the customer shoots from

Printable, no tables wider than the phone screen. Mirrors `refs/ref-04-text.md`.

```markdown
# Съёмка · <slug>

## Как снимать
- Вертикально, 1080×1920 или 4K там, где помечено.
- Каждую фразу целиком, после неё пауза 1–2 с. Сбился — начни фразу заново.
- Снимай по локациям; порядок в рилсе соберётся сам.

## Текст целиком (как прозвучит)
> …

## По локациям
### L1 · за столом, по грудь
1. Я не смонтировал ни секунды этого ролика.
2. …

## Подготовить до съёмки
- [ ] запись экрана: …
- [ ] файлы: …

## После съёмки
Файл в `inbox/`, затем `/reel inbox/<файл> --remake video-projects/<date>-remake-<slug>`.
```
