# Режимы вывода

## `kit` (по умолчанию) — набор для монтажки

`renders/kit/`:

| Файл | Что это | Как ставить |
|---|---|---|
| `clean.mp4` | Чистый монтаж: без пауз, «э-э» и дублей. Таймлайн всех остальных файлов | Основная дорожка |
| `broll/NN-name_0m32s40.mp4` | Полноэкранная врезка (H.264) | Заменяет кадр с точки входа (имя = in-point) |
| `broll/NN-name_0m32s40.mov` | Панель или карточка поверх (ProRes 4444 с альфой) | Дорожка над видео с точки входа |
| `captions.mov` | Субтитры, ProRes 4444 с альфой, вся длина | Верхняя дорожка с 0:00 |
| `captions.srt` | Те же субтитры текстом | Если монтажка делает свои субтитры |
| `TIMING.md` | Каждый клип: in/out, способ постановки, фраза | Шпаргалка |
| `preview.mp4`, `compare.html`, `viewer.html` | Превью со всем вставленным; сравнение до/после; пролистывание клипов | Для просмотра |

ProRes 4444 с альфой открывается в Premiere, Final Cut и DaVinci Resolve. **CapCut:**
поддержка альфы в ProRes зависит от версии; если панели приходят на чёрном фоне —
попроси режим `full` или полноэкранные версии клипов.

## `full` — готовый файл

`renders/final.mp4`: всё вставлено, кодировка по SPEC §9 (1080×1920, H.264 High,
yuv420p, limited range, BT.709, AAC 48 кГц, −14 LUFS, +faststart). Проверка —
`scripts/ru/check-reel.mjs`, должно быть `RESULT: PASS`.

## Превью для ГЕЙТА C

`renders/preview.mp4` — 540×960, быстрый энкод. Только для просмотра. Финал
рендерится один раз, после ГЕЙТА C.

## Почему субтитры не через движок `embedded-captions`

Проверено 2026-10-11 (см. `vendor/SOURCES.md`): его рендер требует матирования
спикера (модель u2net ~168 МБ, минуты CPU на каждые 10 с), тема `anchor` настроена под
1280×720 (на 1920 строка уходит под интерфейс Reels), все шрифты — латинские
подмножества, а переносов строк нет вовсе. Поэтому S5 делает
`scripts/ru/make-captions.mjs`: те же правила «рельса» (≤ 2 строк, ≥ 0,5 с на экране,
плавные появления, тень у глифов), наш пословный транскрипт, кириллические шрифты из
бренда, проверка глифов, рендер HyperFrames в MOV с альфой. Движок
`embedded-captions` остаётся для «встроенных» эффектных субтитров за спикером — по
отдельной просьбе.
