# START — как пользоваться Reels Studio

Кладёшь сырое вертикальное видео в папку, пишешь Claude Code одну команду и получаешь
смонтированный рилс: паузы и дубли вырезаны, есть графика под слова, русские субтитры
и экспорт под Instagram.

---

## 1. Что нужно

- Mac: лицо и вырезка спикера работают через Apple Vision.
- Claude Code.
- Node ≥ 22, git, ffmpeg + ffprobe, Python 3, Google Chrome.
- Xcode Command Line Tools: `xcode-select --install` (для `swift`).
- Python-пакеты: `pip3 install numpy pillow`.

## 2. Установка

```bash
npm ci
npm run setup
npm test
```

`setup` проверяет инструменты и создаёт `.env`, `brand/brand.md`, `lessons.md`,
`refs/NOTES.md` и `brand/music/tracks.json` из шаблонов `*.example`, если их нет.
Эти файлы твои: в гит они не попадают.

## 3. Ключи: `.env`

| Ключ | Зачем |
|---|---|
| `OPENAI_API_KEY` | расшифровка речи (whisper-1), единственный обязательный ключ |
| `TRANSCRIBE_PROVIDER` | `openai` или `elevenlabs` (тогда нужен `ELEVENLABS_API_KEY`) |
| `HIGGSFIELD_API_KEY` | генерация B-roll; необязательно, только по просьбе |

- `.env` не коммитить и никому не отправлять.
- Расшифровка кэшируется по файлу (`.cache/transcripts/`): одно видео дважды не оплачивается.

## 4. Сделай под себя (один раз)

| Файл | Что поменять |
|---|---|
| `brand/brand.md` | цвета, шрифты, субтитры (размер, высота `baseline_y`), CTA, логотип; раздел «Словами»: тон, темы, запреты |
| `brand/fonts/` | свои шрифты, **обязательно с кириллицей** |
| `brand/logo/` | логотип; путь вписать в `brand.md` → `logo` |
| `refs/NOTES.md` | 2–5 рилсов-эталонов: какие приёмы берём, какие нет |
| `lessons.md` | ничего: он заполняется сам после каждого рилса |
| `brand/music/` + `tracks.json` | свои треки; трек без записи о лицензии не используется |
| `brand/sfx/` | свои звуки (`whoosh`, `pop`, `click`, `hit`…); если их нет, звуки синтезируются |

Проще всего попросить Claude: «настрой brand.md под меня: цвет такой-то, шрифт такой-то».

## 5. Монтаж

```
/reel inbox/<файл> — бриф одной строкой
```

| Флаг | Что |
|---|---|
| `--mode kit` | по умолчанию: монтаж, графика, субтитры, превью |
| `--mode full` | сразу готовый MP4 |
| `--density light / medium / heavy` | сколько графики |
| `--review-cuts` | показать вырезанное до сборки |

Остановки, где решаешь ты:
- **Гейт B.** Выбираешь один из трёх хуков и утверждаешь план графики.
- **Гейт C.** Смотришь превью и даёшь правки словами.

Правки автоматически пишутся в `lessons.md`, и следующий рилс их учитывает.

## 6. Повторить чужой рилс

```
/remake inbox/<чужой рилс> — бриф: тема, что оставить, что поменять
```

Получаешь разбор, текст под тебя и план съёмки. Снимаешь, затем:

```
/reel inbox/<твоё видео> --remake video-projects/<дата>-remake-<слаг>
```

## 7. Где что лежит

| Путь | Что там |
|---|---|
| `inbox/` | сюда кладёшь сырое видео |
| `video-projects/<дата-слаг>/` | всё по одному рилсу |
| `…/renders/final.mp4` | готовый ролик; новые версии кладутся рядом, старые не затираются |
| `…/fx/fx.json` | эффекты одного рилса: смена фона, наезды, цвет, зерно, звук, музыка |
| `…/PLAN.json` | план графики и субтитров |
| `brand/` | всё, что общее для всех рилсов |
| `.claude/skills/vladilen-reels/SKILL.md` | главный сценарий: стадии S0–S8 |
| `.claude/commands/` | команды `/reel` и `/remake` |
| `scripts/ru/` | скрипты: транскрипция, чистка, субтитры, сборка, экспорт |
| `SETUP.md` | полная шпаргалка по всем настройкам |

## 8. Важно

- Claude не слышит звук: громкость, музыку и склейки проверяй на слух сам.
- Исходники не меняются, все версии лежат в `video-projects/`.
- Настройки удобнее менять словами («музыку тише», «убери зерно»): Claude сам найдёт нужный файл.
- Факты, цифры и отзывы Claude не придумывает. Если чего-то не знает, спросит.
