# YouTube-ролики в формате «сцена»: как пользоваться

Отдельный флоу для длинных роликов 16:9. Рилсы (`/reel`, `/remake`, `/remake-fast`, `/reel-wide`) он не трогает.
На выходе тёмная фирменная сцена: на ней по одной мысли за раз (иллюстрация, скриншот источника, логотипы,
цифра, цитата), а твоё лицо в узкой плашке справа. Если запись снята говорящей головой, на личных репликах лицо
выходит на весь кадр. Звук по умолчанию только голос.

## 1. Записать

- **Экран + камера** (сцена OBS «YouTube», 1920×1080): экран, справа маленькая карточка с камерой. Лицо будет в
  плашке весь ролик; карточка с камерой вырезается из записи сама.
- **Говорящая голова** (лицо на весь кадр): плашка справа, а на вопросах, личных репликах и выводах лицо
  выходит на весь кадр.
- Говори своими словами. Если ссылаешься на статью, анонс или документацию, назови, где это было («Anthropic в
  документации пишет…»): по этим словам найдётся источник, и на экране будет его скриншот с подсвеченной фразой.
- Длина любая; на 3–5 минутах всё проверено.

## 2. Запустить

```
/youtube ~/Movies/YouTube-2026-11-02.mp4 — про агентов в бизнесе
```

- `--slug agents`: имя проекта (иначе берётся из файла). Проект: `video-projects/<дата>-yt-<slug>/`.
- `--review-plan`: остановиться после плана карточек и показать список (время · карточка · образ · текст ·
  источник) до сборки.

Дальше без вопросов: расшифровка (один платный вызов, повторно не расшифровывается), чистка пауз, проверка
фактов по источникам, скриншоты источников и логотипы, иллюстрации, план карточек, превью 960×540.

## 3. Посмотреть превью

Придёт:
- `renders/stage.preview.mp4`: превью;
- `review/stage-preview-*.png`: листы кадров, по одному на каждую карточку;
- `FACTS.md`: что в речи проверено, что исправлено на экране (неверно услышанные названия, неточные цитаты), что
  проверить тебе (`[проверь: …]`).

Речь не переписывается. Если в речи неточность, исправленный вариант идёт на карточку, и об этом будет в отчёте.

## 4. Правки

Пиши обычными словами, например:
- «на 1:10 вместо текста дай иллюстрацию»;
- «тут лучше скрин с их сайта»;
- «логотип не тот»;
- «карточка опаздывает»;
- «убери метку ИЛЛЮСТРАЦИЯ»;
- «здесь лицо на весь кадр».

Пересобираются только изменённые карточки, остальные берутся из кэша; превью 3 минут собирается примерно за
минуту.

## 5. Финал

«ок» → финал 1920×1080 (`renders/stage.final.mp4`). По желанию дальше тексты для YouTube: главы
(`yt-chapters`), описание (`yt-seo`), название и текст обложки (`yt-package`). Ничего не публикуется и не
загружается.

## Что на экране

| Когда в речи | Что показывается |
|---|---|
| мысль, которую можно нарисовать (команда, система, путь, «чёрная коробка») | иллюстрация на всю сцену, линии рисуются по мере речи; метка «ИЛЛЮСТРАЦИЯ» |
| ссылка на статью, анонс, документацию | скриншот страницы в окне браузера, наезд на фразу и подсветка; «ИСТОЧНИК · домен» |
| названы продукты или компании | настоящие логотипы (с официального сайта или Wikimedia Commons), даты из источников |
| было → стало | сравнение с иконками или логотипами |
| цифра | большая цифра; только та, что сказана или подтверждена |
| точная цитата, термин, шаги | цитата, словарная карточка, шаги |

Правила: факты, цифры и цитаты только настоящие; Meta с пометкой «запрещена в России»; один акцент на кадр;
русский текст только шрифтами бренда.

## Если надо руками

| Команда | Что делает |
|---|---|
| `node scripts/long/web-shot.mjs <url> --out <проект>/assets/web/<имя>.png --phrase "фраза"` | скриншот страницы и место фразы для подсветки |
| `node scripts/long/stage-assemble.mjs <проект> --check` | проверить план карточек |
| `node scripts/long/stage-assemble.mjs <проект> --preview --review` | превью и листы кадров |
| `node scripts/long/stage-assemble.mjs <проект> --final` | финал 1080p (`--loudnorm` выравнивает громкость до −14 LUFS) |
| `node scripts/long/check-stage-cards.mjs` | проверка самих карточек стиля |

В проекте: `CARDS.json` (план карточек), `FACE.json` (где лицо), `mkplan.mjs` (пишет оба плана), `mkill.mjs`
(рисует иллюстрации на `scripts/long/lib/ill.mjs`), `assets/logos/`, `assets/web/`, `assets/ill/`.
Все настройки стиля перечислены в `SETUP.md`, раздел «YouTube».
